# 增补扩笼纪要（ADR · 当日锁死）

- 纪要编号：ADR-2026-11-22-TOPUP-01
- 日期：2026-11-22
- 状态：**已锁定（LOCKED）**——当日锁死；此后任何偏离须新开纪要并保留本纪要，禁止就地改口径。
- 关联事故：`docs/incident/2026-11-22-增补假绿事故复现.md`
- 关联红测：`tests/test_topup_expand.py`

## 一、事故与根因

增补空桩 `POST /api/topup-stub` 只向 `topup_jobs` 插作业票并写审计，
不抬笼面（`cages.amount/available`）、不加账户冻结（`bond_accounts.frozen`）。
对账恒等式两侧都没动，互证灯仍亮绿，属**假绿**。

## 二、两条候选口径（二选一，禁止混用）

- 甲路径：**同笼扩额整笔落库**——一笔提交内完成账户可用扣减（冻结增加）、
  笼总额/可用抬高、笼代推进、作业票与审计落库；任一步失败整笔回滚。
- 乙路径：**旁路影子桥接晋升**——先写增补影子单据，再原子切换笼面与冻结并升代；
  失败作废影子单据，笼与账户零改。

## 三、决策（锁死）

**采用甲路径：同笼扩额整笔落库。** 乙路径（含其 UI 旧称「新笼桥接」）一并禁用，
两条路径不得混用、不得双写。

锁定理由：

1. 本仓 `freeze / release / forfeit` 主链路全部是单连接单提交的整笔事务口径，
   甲路径与母仓事务模型一致，不引入影子态状态机；
2. 增补不产生新笼，笼编码不变、笼代 +1，对账同代公式天然延续；
3. 假绿根因是「作业票与资金面分离」，甲路径把作业票、笼面、冻结放进同一事务，
   从结构上消灭分离窗口。

## 四、甲路径事务步骤（实现口径，逐字对应 `topup_svc.topup_expand`）

入口：`POST /api/topup`，体 `{cage_id, amount, mode}`，仅接受 `mode="同笼扩代"`。

1. 鉴权：写角色（admin/clerk），viewer 403，未登录 401。
2. 抢笼锁 `cage:{cage_id}`（`locks.require_lock`）。抢锁失败：
   HTTP 409，`contention_log` 留一条争用痕，**不写任何业务数据**。
3. 单连接单事务内依次执行，全部成功才 `commit`：
   1. 校验笼存在且状态 ∈ {已冻结, 核验通过, 核验违约, 部分解笼, 部分罚没}；
   2. 校验当事人账户存在且状态=正常；
   3. 校验 `amount <= bond_accounts.balance - bond_accounts.frozen`（容差 1e-9），
      不足 409；
   4. `INSERT topup_jobs`，状态 `已扩笼`，明细记「同笼扩额整笔落库 g{n}→g{n+1}」；
   5. `UPDATE cages SET amount=amount+a, available=available+a,
      generation=generation+1 WHERE id=?`；
   6. `UPDATE bond_accounts SET frozen=frozen+a WHERE party_key=?`
      （**balance 不动**：钱只在当事人可用→冻结间搬，不出系统）；
   7. `write_audit(action='topup_expand', target=cage_code, 载荷含 job_id/金额/前后笼代)`。
4. 任一步抛错：`rollback` 后向上抛出——作业票、笼面、账户冻结**一并回滚**，
   笼与账户保持零改；HTTP 500（业务校验类错误仍为 4xx）。
5. `finally` 释放笼锁并关闭连接。

## 五、偏航处置

- 请求 `mode="新笼桥接"`（乙路径旧称）：写审计 `topup_deviation`（扩笼偏航）并提交该审计，
  随后 HTTP 400 拒绝；`topup_jobs`、笼面、账户零写入。
- 其他非法 mode：HTTP 400。
- 禁止只改页眉/提示文案而不动资金面；禁止保留任何「无资金面变更」的增补入口。

## 六、五页同源口径

增补页、入笼页、账户页、对账页、审计页全部只读同一 SQLite 母仓，禁止页内私算口径：

| 页 | 数据源 |
|----|--------|
| 增补页（增补拆笼 Tab） | `topup_jobs` + `audit_trail`，动作打 `POST /api/topup` |
| 入笼页 | `cages`（amount/available/generation）+ 笼详情内 `topup_jobs` 扩额痕迹 |
| 账户页 | `bond_accounts`，服务端给出 `available=balance-frozen` |
| 对账页 | `reconcile_svc`：笼口径 `available+拨付+罚没=amount`，当事人口径 `frozen=活笼可用合计`，附扩额累计 |
| 审计页 | `audit_trail`（topup_expand / topup_deviation）+ `contention_log` |

只改角标、不改同源数据的，不算过关。
